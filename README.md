# Collections Utility Methods

A Java console application demonstrating utility methods from the `Collections` class.

## Features

- Sorts integers in ascending order
- Sorts integers in descending order
- Finds the minimum element
- Finds the maximum element
- Accepts integers from user input

## Requirements

- Java JDK 8 or later

## Project Structure

```text
CollectionsUtilityMethods/
├── src/
│   └── com/
│       └── internship/
│           └── collections/
│               └── CollectionsUtilityMethods.java
├── .gitignore
└── README.md
```

## Compile

```bash
javac -d out src/com/internship/collections/CollectionsUtilityMethods.java
```

## Run

```bash
java -cp out com.internship.collections.CollectionsUtilityMethods
```

## Concepts Demonstrated

The program uses `Collections.sort()`, `Collections.reverseOrder()`, `Collections.min()`, and `Collections.max()` to process a list of integers.
